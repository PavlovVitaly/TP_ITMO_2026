Вопрос

Объясни мне как ментор. Я начинающий разработчик, изучаю python. Объясни мне простыми словами, как устроены объекты в python, сколько памяти занимают, где хранятся, что происходит при модифицировании полей? Приведи жизненный пример, но не пиши за меня сложный код.

Ответ

Главная мысль: **объект — это отдельная вещь в памяти, а переменная — имя, через которое Python на эту вещь ссылается.**

Представь гардероб в театре. У пальто есть номерок, а у нескольких людей могут быть копии этого номерка. Если один человек передал другому номерок, пальто не стало вторым — оба указывают на одно и то же пальто. В Python похожим образом несколько переменных могут ссылаться на один объект.

Простой пример:

```python
class Cat:
    pass

first = Cat()
first.name = "Мурка"
second = first
first.name = "Буся"

print(second.name)  # Буся
```

`Cat()` создал один объект-кошку. Сначала на неё ссылается имя `first`, затем `second = first` даёт второе имя для той же кошки. Когда мы поменяли её поле `name`, изменился объект — поэтому через `second` тоже видно имя «Буся».

**Где объект хранится?** В обычной работе Python размещает объекты в управляемой им памяти. Упрощённо её часто называют кучей. Переменные в основном хранят ссылки на объекты, а не копии всех их данных. Поэтому присваивание `second = first` не копирует кошку — оно копирует ссылку.

**Что значит изменить поле?** Например, `first.name = "Буся"` — это попросить объект, на который указывает `first`, хранить в поле `name` новое значение. Имя `first` продолжает ссылаться на ту же кошку. Если другая переменная тоже ссылается на неё, новое значение будет видно и через эту переменную.

Если же написать `first = Cat()`, это уже другое действие: имя `first` начнёт ссылаться на новую кошку. Имя `second` при этом всё ещё указывает на старую. Старый объект исчезнет только тогда, когда на него больше никто не ссылается и Python сможет освободить занятую им память.

**Сколько памяти занимает объект?** Одного постоянного числа нет. Размер зависит от типа, содержимого, версии Python и устройства. Для ориентира: в текущем окружении `sys.getsizeof()` показал 28 байт для `42`, 41 байт для пустой строки и 56 байт для пустого списка. Это не универсальные значения для каждого компьютера.

Ещё нюанс: `sys.getsizeof()` показывает размер самого объекта, но не всегда всего, на что тот ссылается. Например, размер списка `[1, 2, 3]` не включает полностью память трёх чисел внутри него. Поэтому не думай о размере объекта как о неизменной «цене» одного экземпляра.

В CPython — самой распространённой реализации Python — объекты обычно освобождаются, когда на них больше не осталось ссылок; сборщик мусора также помогает разбирать циклические ссылки. Важная для начала мысль проще: **пока на объект есть ссылки, им можно пользоваться; когда ссылок больше нет, Python может освободить память.**

Запомни на практике: присваивание часто создаёт ещё одну ссылку, а не копию; изменение поля меняет сам объект. Как с пальто и номерками — номерков может быть несколько, но пальто одно.
